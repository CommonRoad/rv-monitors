# Contributors

RV-Monitors grew out of research and teaching projects at the
[Cyber-Physical Systems Group](https://www.ce.cit.tum.de/cps/) of the Technical University of Munich.
Many people shaped the code base over the years. Thank you to everyone who contributed:

- Sebastian Maierhofer (maintainer): library design, monitoring algorithms, Python bindings
- Yannick Ballnath: Hydra and Hydra 2 monitors, predicate reordering
- Tobias Markus: build system, continuous integration, tooling
- Valentin Merle: configuration simplification
- Florian Lercher: initial-step evaluation
- ge28hoc: early monitor implementations, trace and formula generators, MTL event consuming

Contributions made before the public release keep their authorship in the Git history.
For the commit authors, the history shows names only; e-mail addresses were removed before publication.

To contribute, see [CONTRIBUTING.md](CONTRIBUTING.md).
